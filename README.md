# 📊 Superstore EDA Dashboard

The **Superstore EDA Dashboard** is an **interactive data analysis tool** built with **Streamlit** and **Plotly** to explore Superstore-style datasets.  
It allows users to quickly filter, visualize, and analyze sales, profits, and other key metrics without needing to write a single line of code.

Whether you are a **data analyst**, a **business manager**, or a **student learning EDA**, this tool gives you instant insights with a clean and intuitive interface.


## 🚀 Features

- 📂 **Multiple File Formats Supported**
  - `.csv`, `.xlsx`, `.xls`, `.txt`
- 📅 **Date Range Selection**
  - Filter data between specific start and end dates
- 🌍 **Geographical Filters**
  - Region, State, City
- 📊 **Visualizations**
  - Bar chart: Category-wise sales
  - Pie chart: Region, Segment, Category-wise contribution
  - Line chart: Time-series sales trends
  - Tree map: Hierarchical sales breakdown
  - Scatter plot: Relationship between Sales and Profit
- 📥 **Data Export**
  - Download filtered data as `.csv`
- 📜 **Expandable Data Table**
  - View data directly within the dashboard
- 🎨 **Customizable Themes**
  - Styled tables and charts for better readability

---

## 🛠️ Tech Stack

- **Python 3.9+**
- **Streamlit** - For building interactive dashboards
- **Pandas** - For data cleaning & manipulation
- **Plotly Express** - For interactive visualizations
- **NumPy** - For numerical operations
- **OpenPyXL** - For reading Excel files
